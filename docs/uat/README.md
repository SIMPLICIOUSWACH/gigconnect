# User acceptance testing kit

Everything needed to run the user acceptance testing (UAT) the project proposal describes: a sample of Strathmore
University students in both roles, scripted tasks, a check against Nielsen's ten usability heuristics, and a rating of
how relevant participants find their recommendations.

| File | What it is |
|---|---|
| [plan.md](plan.md) | Who takes part, how a session runs, what is measured and how to prepare |
| [freelancer-tasks.md](freelancer-tasks.md) | The task script for freelancer participants |
| [client-tasks.md](client-tasks.md) | The task script for client participants |
| [relevance-rating.md](relevance-rating.md) | How freelancers rate their top 5 and top 10 recommendations, and how the answers are counted |
| [heuristic-checklist.md](heuristic-checklist.md) | Nielsen's ten heuristics, screen by screen, with a severity scale |
| [sus.md](sus.md) | The System Usability Scale. **An optional extra, not in the proposal** |
| [results.md](results.md) | Empty result sheets to fill in during and after the sessions |

The result sheets are left empty on purpose. Nothing in this folder is a result yet.
